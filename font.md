# Typography System

1. **Primary Font (Headings):** 'Montserrat' or 'Playfair Display' (imported via `next/font/google`). This gives a strong, established corporate presence.
2. **Secondary Font (Body Text):** 'Inter' or 'Roboto'. Highly legible, clean sans-serif for descriptions, data, and smaller text elements.
3. **Hierarchy:** 
   - H1: Bold, tight letter spacing, high contrast.
   - H2/H3: Semi-bold, clear distinction from body text.
   - Body: 16px to 18px base size, comfortable line-height (1.6) for readability.
4. Use Tailwind typography classes (`text-4xl`, `font-bold`, `tracking-tight`) to enforce this hierarchy strictly.
